| 파일 | 설명 |
| --- | --- |
| `vocab.html` | 🐣 **단어 쏙쏙 암기장**: 사진으로 넣는 초등학생용 영단어 암기장 |

## 🐣 단어 쏙쏙 암기장 (`vocab.html`)

1. **📸 사진으로 단어 넣기**: 단어장을 찍으면 영어와 한국어 뜻을 자동으로 읽어요. 읽은 결과를 확인하고 고친 뒤 저장해요. (무료 글자 인식 Tesseract.js, 직접 입력도 가능)
   - **표 단어장** (`No. | Word | Meaning`): 영단어가 모인 열을 Word 칸으로, 그 오른쪽 한글 열을 Meaning 칸으로 나눠 읽어요. 번호 칸·머리줄·표 바깥 글자는 버리고, 뜻이 여러 개면 쉼표로 나눠요 (`;`도 쉼표로 바꿔요).
   - 뒷장 비침을 지우고, 뜻 칸은 한국어 전용 인식으로 한 번 더 읽어 더 정확한 쪽을 골라요.
   - 표가 아닌 단어장은 "줄글 방식으로 다시 읽기"를 눌러요.
   - **📐 칸 직접 맞추기** (더 정확): ① 단어 칸의 네 모서리를 끌어 맞추면 비스듬한 사진도 반듯하게 펴요 → ② 표 선을 자동으로 찾아 영어 칸·뜻 칸·줄 경계를 맞춰 두고, 선을 끌어 고칠 수 있어요 (가운데는 이동, 끝부분은 기울기). 끄는 동안 돋보기가 떠요. 칸마다 잘라서 영어는 영어로, 뜻은 한국어로 따로 읽어요.
2. **✏️ 시험 모드 선택**: 🔤 스펠링 쓰기 / 🇰🇷 뜻 쓰기 / 🎲 랜덤
   - 스펠링: 💡 힌트 2단계 (첫 글자 → 절반 공개), 🔊 소리 듣기
   - 뜻: 비슷한 표현도 정답 처리, "표현만 달라요" 버튼으로 맞은 걸로 바꾸기
3. **⭐ 자주 틀리는 단어**: 틀린 단어는 자동으로 스크랩돼요. 힌트 없이 연속 3번 맞히면 졸업 🎓
4. **🔤 발음기호 · 🔊 발음 듣기**: 저장하면 발음기호와 사람 녹음 발음을 찾아 둬요 (Free Dictionary API). 녹음이 없거나 인터넷이 안 되면 기기의 음성 읽기(미국 발음)로 읽어요.
5. **📚 주차별 단어장**: 시험 범위마다 단어장을 나눠요. 시험 볼 때 여러 단어장을 섞을 수도 있어요.

단어와 기록은 기기의 브라우저(localStorage)에 저장돼요. 첫 화면 아래 **💾 백업** 칸에서 백업 파일(`ssokssok-backup-날짜.json`)로 저장하고 불러올 수 있어요. 새 단어를 넣었거나 마지막 백업 후 7일이 지나면 첫 화면에서 백업하라고 알려 줘요.

> 💸 **과금 없음**: 유료 API나 API 키를 쓰지 않아요. 글자 인식(Tesseract.js), 사전(Free Dictionary API), 음성 읽기(기기 내장), 글꼴(Google Fonts) 모두 무료예요.
>
> 사진 인식과 발음기호는 인터넷 연결이 필요해요. 처음 사진을 읽을 때는 인식 도구를 내려받느라 조금 오래 걸려요.

## ⚫ 윤서의 오목 놀이터 (`omok.html`)

가로, 세로, 대각선으로 내 돌 5개를 먼저 이으면 이겨요. (6개 이상 이어도 이겨요. 삼삼 금지 같은 어려운 규칙은 없어요.)

1. **누구랑 할까요?**: 🐱 모찌 (쉬움) / 🦊 루루 (보통) / 🦄 오로라 (어려움) / 👭 둘이서 (한 화면에서 번갈아)
   - 쉬움: 가끔 실수해요. 컴퓨터 돌이 4개가 되면 막을 자리를 빨갛게 알려 주고, 내가 이길 자리가 있으면 귀띔해 줘요.
   - 보통: 4개는 꼭 막고, 3개도 거의 막아요.
   - 어려움: 4를 연달아 만들어 이기는 수를 찾고, 상대의 그런 수도 미리 끊어요. 엄마 아빠도 쉽지 않아요.
2. **판 크기**: 11×11 / 13×13 / 15×15, **돌 모양**: 진주 / 마카롱 / 하트별 / 냥멍(🐱🐶), **누가 먼저**
3. **↩️ 무르기**, **💡 힌트** (한 판에 3번, 왜 좋은 자리인지 말해 줘요), **✋ 두 번 눌러 놓기** (터치할 때 실수 방지, 끌 수 있어요)
4. 친구별로 이긴 횟수가 ⭐로 쌓이고, 하던 판은 자동 저장돼서 다음에 이어서 할 수 있어요 (브라우저 localStorage).
