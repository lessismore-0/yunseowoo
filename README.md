## 🐣 단어 쏙쏙 암기장 (`vocab.html`)

1. **📸 사진으로 단어 넣기**: 단어장을 찍으면 영어와 한국어 뜻을 자동으로 읽어요. 읽은 결과를 확인하고 고친 뒤 저장해요. (무료 글자 인식 Tesseract.js, 직접 입력도 가능)
   - **표 단어장** (`No. | Word | Meaning`): 영단어가 모인 열을 Word 칸으로, 그 오른쪽 한글 열을 Meaning 칸으로 나눠 읽어요. 번호 칸·머리줄·표 바깥 글자는 버리고, 뜻이 여러 개면 쉼표로 나눠요 (`;`도 쉼표로 바꿔요).
   - 뒷장 비침을 지우고, 뜻 칸은 한국어 전용 인식으로 한 번 더 읽어 더 정확한 쪽을 골라요.
   - 표가 아닌 단어장은 "줄글 방식으로 다시 읽기"를 눌러요.
2. **✏️ 시험 모드 선택**: 🔤 스펠링 쓰기 / 🇰🇷 뜻 쓰기 / 🎲 랜덤
   - 스펠링: 💡 힌트 2단계 (첫 글자 → 절반 공개), 🔊 소리 듣기
   - 뜻: 비슷한 표현도 정답 처리, "표현만 달라요" 버튼으로 맞은 걸로 바꾸기
3. **⭐ 자주 틀리는 단어**: 틀린 단어는 자동으로 스크랩돼요. 힌트 없이 연속 3번 맞히면 졸업 🎓
4. **🔤 발음기호**: 저장하면 발음기호를 자동으로 찾아 표시해요 (Free Dictionary API). 🔊 미국 발음 듣기
5. **📚 주차별 단어장**: 시험 범위마다 단어장을 나눠요. 시험 볼 때 여러 단어장을 섞을 수도 있어요.

단어와 기록은 기기의 브라우저(localStorage)에 저장돼요. 첫 화면 아래 **💾 백업** 칸에서 백업 파일(`ssokssok-backup-날짜.json`)로 저장하고 불러올 수 있어요. 새 단어를 넣었거나 마지막 백업 후 7일이 지나면 첫 화면에서 백업하라고 알려 줘요.

> 사진 인식과 발음기호는 인터넷 연결이 필요해요. 처음 사진을 읽을 때는 인식 도구를 내려받느라 조금 오래 걸려요.
